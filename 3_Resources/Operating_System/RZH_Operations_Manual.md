# SECTION 3: COMMODITY MASTER SPECIFICATIONS

## 3.1 NICKEL ORE — LIMONITE

Nickel ore is ECONARES' primary commodity. Master these specs completely.

### Grade Classification (Philippine Origin):

| Grade Code | Nickel (Ni%) | Iron (Fe%) | Typical Use | Source Regions |
|------------|-------------|------------|-------------|---------------|
| LOW-1 | 0.80 – 1.19% | > 48% | NPI / Ferronickel feed | Surigao, Mindanao |
| LOW-2 | 1.20 – 1.29% | ≤ 20% | NPI / Export blend | Surigao, Dinagat |
| MED-1 | 1.30 – 1.39% | ≤ 30% | Stainless steel mills | Palawan, Zambales |
| MED-2 | 1.40 – 1.49% | ≤ 25% | Premium NPI feed | Palawan |
| HIGH | 1.50 – 1.59% | ≤ 20% | High-grade stainless | Rio Tuba, Palawan |
| PREMIUM | ≥ 1.60% | ≤ 20% | Specialty alloys | Rio Tuba |

### Memory Anchor — James Kwik Method:
> "LOW is BUDGET — Med is WORKHORSE — HIGH is VAULT"
> Grades rise → use cases narrow → price climbs

### Key Specifications to Memorize:
- Limonite ore: oxide ore, forms in tropical weathering
- Nickel content + low iron = premium
- Penalty elements: MgO, Al2O3, SiO2 (watch for high impurity grades)
- Typical moisture: 25-35% (wet basis)
- Philippines: major limonite producer, especially Surigao and Palawan

### Typical Deal Terms:
- MOQ: 10,000 – 50,000 DMT per shipment
- Incoterm: FOB Philippines origin (Surigao, Manila, or Palawan)
- Payment: 50% Down Payment, balance against BL copy
- Inspection: SGS or CISS at load port

# SECTION 4: THE ECONARES DEAL PROCESS

## 4.1 Standard Deal Rules

**THESE ARE NON-NEGOTIABLE — MEMORIZE THEM:**

1. **50% DOWN PAYMENT** — All buyers, all deals, no exceptions
2. **FOB ORIGIN ONLY** — ECONARES arranges logistics to port; buyer books vessel. No CIF, no CFR.
3. **DSR = HTML DRAFT FIRST** — Always present as draft. Send only after RZH confirms.
4. **CEO MEETINGS** — Book through ece.eleguinresources@yahoo.com only
5. **MGB/DENR COMPLIANCE** — Omit from first contact. Never volunteer regulatory details upfront.

## 4.2 Deal Stages

```
STAGE 1: LEAD IDENTIFICATION
    → Research buyer, find decision-maker contact
    → Verify company is active in relevant commodity
    → Check if in HubSpot — if not, create contact

STAGE 2: INITIAL OUTREACH
    → Send personalized email (draft first, present to RZH, confirm before sending)
    → Log outreach in HubSpot with date + subject line
    → Set lead status to IN_PROGRESS

STAGE 3: QUALIFICATION
    → Confirm: commodity interest? volume? timeline? grade specs?
    → Identify: budget? current supplier? decision-maker?
    → Log all qualification notes in HubSpot

STAGE 4: PROPOSAL / DSR
    → Draft DSR in HTML format
    → Include: quantity, grade, FOB price, delivery timeline, payment terms
    → Present to RZH before sending
    → After RZH confirms: create Gmail draft and send

STAGE 5: NEGOTIATION
    → Log all counter-offers in HubSpot
    → Maintain 50% DP minimum
    → All price revisions documented

STAGE 6: CONTRACT / MOA
    → Coordinate with CEO for contract review
    → Ensure MGB/DENR permits in place before loading

STAGE 7: EXECUTION
    → Track shipment milestones: loading, departure, arrival
    → Payment collection: 50% DP on contract, balance against BL
    → File all documents in Obsidian

STAGE 8: POST-DEAL
    → Log completion in HubSpot
    → Update lead status to CLOSED WON
    → Identify referral opportunities
```
