# 0 Inbox

> **Capture point for everything.** New notes, ideas, half-formed thoughts, research fragments, buyer leads, price observations. Process this every week.

## Processing Rule (Zettelkasten + PARA)

1. **Read** — What is this note about?
2. **Decide** — Where does it belong?
   - Active deal, campaign, or deal with a deadline → `1_Projects`
   - Ongoing operational area (no deadline) → `2_Areas`
   - Permanent reference, SOP, or study material → `3_Resources`
   - Completed, cancelled, or superseded → `4_Archives`
3. **Link** — Add `[[wikilinks]]` to related notes in destination folder.
4. **Tag** — Add relevant tags.
5. **Index** — Update the destination folder's INDEX.md.
