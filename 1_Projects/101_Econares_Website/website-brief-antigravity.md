### Project Type
B2B Corporate Website — Commodities Trading & Logistics

## 3. REFERENCE WEBSITE ANALYSIS: BULK-ORE.COM

### Design Philosophy
Bulk Ore exemplifies the **"minimalist corporate authority"** aesthetic — a design language that communicates reliability, expertise, and global reach through restraint rather than excess.

### Key Design Elements to Emulate

#### A. Visual Language
| Element | Bulk Ore Approach | ECONARES Application |
|---------|-------------------|----------------------|
| **Layout Rhythm** | Generous whitespace, single-column hero, structured content blocks | Apply same breathing room; ECONARES multi-commodity focus needs clear visual hierarchy |
| **Typography** | Clean sans-serif, strong hierarchy (H1 to H2 to body), minimal text | Use for headlines, taglines, and value propositions |
| **Imagery** | Minimal — SVG logos, subtle backgrounds, no stock photo clutter | Use sparingly: aerial port imagery, logistics imagery only if authentic |
| **Color Philosophy** | Dark/gold/slate neutrals — conveys premium commodity trading | **CRITICAL: Incorporate color scheme from client-provided image (see Section 4)** |

#### B. Content Structure
1. **Hero Section** — Single compelling statement of specialization
2. **Value Proposition Block** — Who they are in 2-3 sentences
3. **Expertise/Commodities Section** — Clear listing with brief descriptors
4. **Contact/CTA Section** — Minimal, direct, professional

#### C. UX Principles
- Zero cognitive friction — every element earns its place
- Mobile-first responsive (B2B buyers research on mobile)
- Fast load times (image optimization, minimal JS)
- Clear pathways to contact/inquiry

#### DESIGN APPLICATION NOTES
- **Background:** Steel/Network Blue gradient with white node accents — suggests connectivity, network, and global reach

## 5. DESIGN DO's AND DON'Ts

### DO
- Emulate Bulk Ore's clean, spacious layout with clear visual hierarchy
- Use the exact color palette from the client-provided image
- Include professional photography only (no generic stock imagery of smiling businesspeople shaking hands)
- Maintain clean information architecture
- Optimize for fast load times and mobile viewing
- Include clear CTAs: "Contact Us," "Request a Quote," "Partner With Us"
- Show geographic coverage: Philippines map with Visayas/Mindanao highlighted
- List accredited suppliers (Mabuhay Filcement, Goodfound, Philcement, Republic Cement)
- Add compliance trust signals (MGB/DENR awareness — generally phrased)

### DON'T
- Clutter the design with excessive text, icons, or stock photos
- Use bright, playful colors inconsistent with commodity trading professionalism
- Include pricing (commodity prices fluctuate)
- Use "Trading Corporation" in company name
- Lead with MGB/DENR compliance details in hero section
- Use markdown formatting in final deliverables
