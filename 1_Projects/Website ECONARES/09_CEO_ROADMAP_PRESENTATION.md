# SLIDE 4: WHAT HUBSPOT INTEGRATION DOES (DEEP DIVE)

## BEFORE PHASE 1:
1. PROSPECT SUBMITS RFQ ON WEBSITE
2. FORMSPIEE EMAILS `sales@econares.com`
3. RZH MANUALLY COPIES DATA INTO HUBSPOT
4. RZH MANUALLY CREATES DEAL
5. RZH MANUALLY CREATES FOLLOW-UP TASK
6. **TIME ELAPSED: 30 MINUTES TO 4 HOURS**
7. RISK: RZH IS ON LEAVE → RFQ IS LOST

## AFTER PHASE 1:
1. PROSPECT SUBMITS RFQ ON WEBSITE
2. **API ROUTE AUTO-CREATES HUBSPOT CONTACT** (<5 SEC)
3. **API ROUTE AUTO-CREATES DEAL IN PIPELINE** (<5 SEC)
4. **API ROUTE AUTO-CREATES FOLLOW-UP TASK (DUE +48H)** (<5 SEC)
5. **PROSPECT GETS CONFIRMATION EMAIL** (<30 SEC)
6. **TIME ELAPSED: 30 SECONDS**
7. **RISK: ZERO — AUTOMATED, AUDITABLE, RELIABLE**
