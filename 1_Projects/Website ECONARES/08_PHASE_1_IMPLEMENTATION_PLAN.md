## 1.1 WORK STREAM A — LEAD PIPELINE AUTOMATION

### FEATURE A1: HUBSPOT CRM INTEGRATION
**OBJECTIVE:** REPLACE FORMSPIREE WITH DIRECT HUBSPOT CRM INTEGRATION. RFQ SUBMISSIONS AUTO-CREATE CONTACTS, DEALS, AND FOLLOW-UP TASKS.

**DEPENDENCIES:**
- HUBSPOT PRIVATE APP TOKEN (RZH HAS — STORE IN `~/.hermes/.env`)
- HUBSPOT CUSTOM PROPERTIES: `RFQ Type`, `RFQ Source`, `Commodity Interest`, `Sales Officer Assignment`
- ASTRO SERVER-SIDE ROUTE MODE (CHANGE `output: 'static'` TO `output: 'hybrid'`)

**TECHNICAL APPROACH:**

1. CREATE API ROUTE: `src/pages/api/rfq.ts`
2. ROUTE HANDLER:
   - VALIDATE INCOMING FORM DATA (ZOD SCHEMA)
   - CALL HUBSPOT CRM API V3 TO CREATE/UPDATE CONTACT
   - CREATE DEAL IN HUBSPOT PIPELINE
   - CREATE FOLLOW-UP TASK (DUE +48H)
   - SEND CONFIRMATION EMAIL VIA HUBSPOT TRANSACTIONAL
   - RETURN SUCCESS/ERROR JSON TO CLIENT
3. UPDATE FRONTEND `src/pages/contact.astro` TO POST TO `/api/rfq`
4. KEEP FORMSPIREE AS FALLBACK (env var `USE_HUBSPOT=true/false`)

**HUBSPOT API ENDPOINTS USED:**
- `POST /crm/v3/objects/contacts` — CREATE CONTACT
- `POST /crm/v3/objects/deals` — CREATE DEAL
- `POST /crm/v3/objects/tasks` — CREATE FOLLOW-UP TASK

**ACCEPTANCE CRITERIA:**
- [ ] RFQ FORM SUBMITS AND RETURNS SUCCESS WITHIN 3 SECONDS
- [ ] HUBSPOT CONTACT CREATED WITH NAME, EMAIL, PHONE, COMPANY
- [ ] HUBSPOT DEAL CREATED WITH COMMODITY, QUANTITY, DELIVERY DATE
- [ ] FOLLOW-UP TASK CREATED, DUE 48H FROM NOW
- [ ] CONFIRMATION EMAIL RECEIVED BY PROSPECT WITHIN 30 SECONDS
- [ ] ERROR HANDLING: BAD EMAIL RETURNS 400, API FAILURE RETURNS 500
- [ ] FORMSPIREE FALLBACK WORKS WHEN `USE_HUBSPOT=false`

**TEST PLAN:**
1. SUBMIT VALID RFQ → VERIFY HUBSPOT CONTACT + DEAL + TASK CREATED
2. SUBMIT INVALID EMAIL → VERIFY 400 ERROR
3. SIMULATE HUBSPOT API DOWN → VERIFY FALLBACK TO FORMSPIREE
4. LOAD TEST: 10 SIMULTANEOUS SUBMISSIONS

**EFFORT:** M (16-24 H)
**DEPENDENCIES BLOCKING:** NONE (HUBSPOT TOKEN ALREADY EXISTS)
