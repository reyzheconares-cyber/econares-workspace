# 1. QUICK START (10 MINUTES)

IF YOU ALREADY KNOW WHAT YOU'RE DOING, HERE ARE THE 3 STEPS:

```bash

cp -r /path/to/USB/econares-website-staging /c/Users/rzh/Desktop/

# 2. INSTALL DEPENDENCIES
cd /c/Users/rzh/Desktop/econares-website-staging/website
npm install --no-audit --no-fund

# 3. START THE LOCAL PREVIEW SERVER
PUBLIC_SITE_URL="https://econares-website.vercel.app" \
  npx astro preview --host 127.0.0.1 --port 4321
```

THEN OPEN http://127.0.0.1:4321/ IN A BROWSER.

THIS IS WHAT YOU NEED FOR A WORKING LOCAL DEPLOYMENT:

```
econares-website-usb/                       (USB ROOT FOLDER)
├── README_DEPLOY.md                        (this file — keep it on the USB)
├── DEPLOY_QUICK_START.bat                  (Windows one-click deploy)
├── DEPLOY_QUICK_START.sh                   (Mac/Linux one-click deploy)
├── website/                                (Astro subproject)
│   ├── package.json                        (dependency manifest)
│   ├── package-lock.json                   (lockfile for reproducible builds)
│   ├── astro.config.mjs                    (Astro config)
│   ├── tailwind.config.mjs                 (Tailwind config)
│   ├── tsconfig.json                       (TypeScript config, if present)
│   ├── src/                                (Astro source files, 1.5 MB)
│   ├── public/                             (static assets, ~10 MB)
│   │   ├── logo.png                        (4.3 MB official logo)
│   │   ├── favicon.svg
│   │   ├── robots.txt
│   │   └── products/                       (20 AI product images, ~5 MB)
│   ├── scripts/                            (build/verify scripts)
│   ├── .gitignore
│   └── dist/                               (pre-built static site, 11 MB)
└── presentation/                           (CEO presentation docs, optional)
    ├── 00_READ_ME_FIRST.md
    ├── 01_WEBSITE_RATIONALE.md
    ├── 02_COMPENSATION_CASE.md
    ├── 03_SLIDES.md
    ├── 04_DEMO_PRACTICE_SCRIPT.md
    └── 05_CHEAT_SHEET.md
```

**ESTIMATED USB SIZE:** ~50 MB (uncompressed) OR ~15 MB (zip compressed)

**THE `node_modules/` FOLDER (~400 MB) IS NOT NEEDED** — IT IS REGENERATED BY `npm install` ON THE TARGET MACHINE.

## 2.2 RECOMMENDED: USE A ZIP

TO CREATE THE USB PACKAGE ON YOUR CURRENT MACHINE:

**WINDOWS POWERSHELL:**

```powershell
# OPEN POWERSHELL, NAVIGATE TO PARENT FOLDER
cd C:\Users\reyma\Documents

# CREATE ZIP
Compress-Archive -Path "econares-website-staging\website" `
                 -DestinationPath "D:\econares-website-usb.zip" `
                 -Force
```

**GIT-BASH / MAC / LINUX:**

```bash
cd /c/Users/reyma/Documents

# CREATE ZIP (EXCLUDE node_modules AND dist WILL BE INCLUDED)
zip -r /d/econares-website-usb.zip econares-website-staging/website \
  -x "*/node_modules/*" "*/.astro/*"
```

**THIS PRODUCES A ~15-25 MB ZIP** THAT FITS ON ANY USB STICK.

## 2.3 WHAT TO EXCLUDE FROM THE COPY

**DO NOT COPY:**
- ❌ `node_modules/` (400 MB, regenerable via `npm install`)
- ❌ `.git/` (50 MB, you have it on GitHub)
- ❌ `.astro/` (10 MB, generated cache)
- ❌ `scripts-tmp/` (one-shot scripts, not needed)
- ❌ `.tmp.drivedownload/` and `.tmp.driveupload/` (Google Drive sync temp)
- ❌ `*.swp`, `*.swo`, `*.bak`, `*.tmp`, `*.lnk` (editor swap files)
- ❌ `desktop.ini` (Windows folder metadata)

**WHAT YOU MUST COPY:**
- ✅ `website/package.json` AND `website/package-lock.json` (lockfile is critical for reproducible builds)
- ✅ `website/src/` (all source code)
- ✅ `website/public/` (all static assets including product images)
- ✅ `website/scripts/` (build/verify scripts)
- ✅ `website/astro.config.mjs` and `website/tailwind.config.mjs`
- ✅ `website/dist/` (pre-built, optional — only needed if you don't want to rebuild)

# 4. DEPLOYMENT STEPS — 3 OPTIONS

## 4.1 OPTION A: ONE-CLICK DEPLOY (RECOMMENDED)

I'LL CREATE A WINDOWS BATCH FILE AND A BASH SCRIPT THAT AUTOMATE THE WHOLE PROCESS. JUST DOUBLE-CLICK AND WAIT.

### WINDOWS: `DEPLOY_QUICK_START.bat`

```bat
@echo off
REM ===========================================
REM ECONARES WEBSITE - ONE-CLICK LOCAL DEPLOY
REM ===========================================
echo.
echo ==========================================
echo ECONARES WEBSITE - LOCAL DEPLOYMENT
echo ==========================================
echo.

cd /d "%~dp0website"

echo [STEP 1/3] Checking Node.js...
node --version >nul 2>&1
if errorlevel 1 (
  echo ERROR: Node.js is not installed.
  echo Download from: https://nodejs.org/
  pause
  exit /b 1
)
node --version

echo.
echo [STEP 2/3] Installing dependencies (1-2 min)...
call npm install --no-audit --no-fund
if errorlevel 1 (
  echo ERROR: npm install failed.
  pause
  exit /b 1
)

echo.
echo [STEP 3/3] Starting preview server...
echo.
echo ==========================================
echo  SITE IS LIVE AT: http://127.0.0.1:4321/
echo  PRESS CTRL+C TO STOP
echo ==========================================
echo.

set PUBLIC_SITE_URL=https://econares-website.vercel.app
call npx astro preview --host 127.0.0.1 --port 4321

pause
```

### MAC/LINUX: `DEPLOY_QUICK_START.sh`

```bash
#!/usr/bin/env bash
# ECONARES WEBSITE - ONE-CLICK LOCAL DEPLOY

set -e
cd "$(dirname "$0")/website"

echo "=========================================="
echo "ECONARES WEBSITE - LOCAL DEPLOYMENT"
echo "=========================================="
echo

echo "[STEP 1/3] Checking Node.js..."
if ! command -v node >/dev/null 2>&1; then
  echo "ERROR: Node.js is not installed."
  echo "Download from: https://nodejs.org/"
  exit 1
fi
node --version

echo
echo "[STEP 2/3] Installing dependencies (1-2 min)..."
npm install --no-audit --no-fund

echo
echo "[STEP 3/3] Starting preview server..."
echo
echo "=========================================="
echo " SITE IS LIVE AT: http://127.0.0.1:4321/"
echo " PRESS CTRL+C TO STOP"
echo "=========================================="
echo

PUBLIC_SITE_URL="https://econares-website.vercel.app" \
  npx astro preview --host 127.0.0.1 --port 4321
```

### USAGE

1. COPY THE ENTIRE `econares-website-usb/` FOLDER TO THE TARGET MACHINE
2. **WINDOWS:** DOUBLE-CLICK `DEPLOY_QUICK_START.bat`
3. **MAC/LINUX:** OPEN TERMINAL, NAVIGATE TO FOLDER, RUN `bash DEPLOY_QUICK_START.sh`
4. WAIT 1-2 MINUTES FOR `npm install` TO COMPLETE
5. BROWSER AUTOMATICALLY OPENS (OR MANUALLY OPEN) http://127.0.0.1:4321/
6. THE SITE IS LIVE

# 6. TROUBLESHOOTING

## 6.1 "NODE.JS IS NOT INSTALLED"

**SYMPTOM:** `node: command not found` OR `'node' is not recognized as an internal or external command`

**FIX:**
1. DOWNLOAD NODE.JS LTS FROM https://nodejs.org/
2. RUN THE INSTALLER WITH DEFAULT OPTIONS
3. **IMPORTANT:** ENSURE "ADD TO PATH" IS CHECKED
4. CLOSE AND REOPEN YOUR TERMINAL/COMMAND PROMPT
5. RUN `node --version` TO VERIFY

## 6.2 "NPM INSTALL FAILS WITH EACCES OR PERMISSION ERROR"

**SYMPTOM:** `npm ERR! code EACCES` OR `permission denied`

**FIX (LINUX/MAC):**
```bash
sudo chown -R $USER:$USER /path/to/econares-website-usb/website
```

**FIX (WINDOWS):**
- RUN POWERSHELL AS ADMINISTRATOR
- OR MOVE THE FOLDER OUT OF `C:\Program Files\` (PERMISSION-RESTRICTED)

## 6.3 "PORT 4321 IS ALREADY IN USE"

**SYMPTOM:** SERVER PRINTS "PORT 4321 IS IN USE, TRYING ANOTHER ONE..."

**FIX (OPTION 1): USE A DIFFERENT PORT**
```bash
npx astro preview --host 127.0.0.1 --port 5000
# THEN OPEN http://127.0.0.1:5000/
```

**FIX (OPTION 2): KILL THE PROCESS USING THE PORT**

**WINDOWS POWERSHELL:**
```powershell
netstat -ano | findstr :4321
# NOTE THE PID (LAST COLUMN)
taskkill /F /PID <PID>
```

**MAC/LINUX:**
```bash
lsof -i :4321
# NOTE THE PID
kill -9 <PID>
```

## 6.4 "SITE LOADS BUT IMAGES ARE BROKEN"

**SYMPTOM:** GRAY BOXES WITH ALT TEXT WHERE PRODUCT IMAGES SHOULD BE

**FIX:** THE `public/products/` FOLDER IS MISSING OR INCOMPLETE. COPY IT FROM THE USB OR RE-DOWNLOAD:
- ALL 20 PRODUCT IMAGES (steam-coal.jpg, metallurgical-coke.jpg, etc.)
- ENSURE THEY ARE IN `website/public/products/`, NOT `website/src/public/products/`

## 6.5 "SITE LOADS SLOWLY"

**SYMPTOM:** PAGE TAKES MORE THAN 5 SECONDS TO LOAD

**POSSIBLE CAUSES:**
1. **NPM INSTALL STILL RUNNING** → WAIT FOR IT TO FINISH
2. **DIST FOLDER IS HUGE** → THIS IS NORMAL FOR A STATIC SITE WITH 20 IMAGES
3. **ANTIVIRUS SCANNING** → TEMPORARILY DISABLE OR ADD EXCEPTION
4. **TARGET MACHINE IS SLOW** → USE A NEWER MACHINE OR RUN `npm run build` TO REBUILD

## 6.6 "FORMSPREE FORM DOESN'T SUBMIT"

**SYMPTOM:** CONTACT FORM DOESN'T SEND, OR SHOWS ERROR

**CAUSE:** THE FORM POSTS TO `https://formspree.io/f/mlgkvevq`, WHICH REQUIRES INTERNET ACCESS. IF THE TARGET MACHINE HAS NO INTERNET, THE FORM WILL NOT WORK.

**FIX (NO INTERNET):** THE FORM WILL SHOW A "FAILED TO SUBMIT" ERROR. THIS IS BY DESIGN. FOR OFFLINE TESTING, JUST VERIFY THE FORM UI RENDERS CORRECTLY — IT DOES NOT NEED TO SUBMIT TO WORK.

**FIX (WITH INTERNET):** CHECK THAT THE FORM POSTS AND A SUCCESS MESSAGE APPEARS. THE EMAIL GOES TO THE CONFIGURED RECIPIENT (CURRENTLY EZE.ELEGUINRESOURCES@YAHOO.COM).

## 6.7 "ASTRO BUILD FAILS"

**SYMPTOM:** `npm run build` ERRORS OUT

**FIX:**
```bash
# CLEAR ASTRO CACHE
cd website
rm -rf .astro dist

# REBUILD
npm run build
```

IF STILL FAILS, CHECK NODE.JS VERSION: `node --version`. MINIMUM v18, RECOMMENDED v20+.

# 9. POST-DEPLOYMENT NOTES

## 9.1 SHUTTING DOWN THE LOCAL SERVER

WHEN YOU'RE DONE WITH THE LOCAL DEMO:
- PRESS `CTRL+C` IN THE TERMINAL WHERE THE SERVER IS RUNNING
- OR CLOSE THE TERMINAL WINDOW

THE SERVER WILL STOP AND PORT 4321 WILL BE RELEASED.

## 9.2 UPDATING THE SITE

IF YOU EDIT THE SOURCE FILES (`website/src/` OR `website/public/`):
1. STOP THE PREVIEW SERVER (CTRL+C)
2. RUN `npm run build`
3. RUN `node scripts/generate-sitemap.mjs`
4. RESTART THE PREVIEW SERVER

OR USE `npm run dev` FOR LIVE-RELOAD DURING DEVELOPMENT (NOT RECOMMENDED FOR PRESENTATION).

## 9.3 MAKING THE SITE PERMANENT

FOR A PERMANENT DEPLOYMENT, USE ONE OF:
- **VERCEL:** https://vercel.com (FREE, 30-SECOND DEPLOY, RECOMMENDED FOR DEMO)
- **NETLIFY:** https://netlify.com (FREE, 30-SECOND DEPLOY, GOOD ALTERNATIVE)
- **CLOUDFLARE PAGES:** https://pages.cloudflare.com (FREE, BEST FOR PRODUCTION)
- **NAMECHEAP CPANEL:** UPLOAD `dist/` TO `public_html/` (PAID, FOR econares.com)

SEE `VERCEL_DEPLOY.md` AND `docs/deploy-namecheap-and-cloudflare.md` FOR FULL GUIDES.
